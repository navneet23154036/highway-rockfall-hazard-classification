Dataset composition

355 rated slopes · 20 Colorado routes

Within-group score ranking: bottom 30% Low, middle 40% Moderate, top 30% High. Ties affect the final class counts.

What the model uses

Set A · 9 features
Six slope and ditch measurements, rock type, slope type and engineering region.

Set B · 14 features (deployed model)
Set A plus rockfall frequency, precipitation, freeze–thaw, seepage and aspect ratings.

The five ratings are components of the hazard total, so some of the performance gain reflects partial target information.

About this implementation

This interface follows the CDOT model notebook: a tuned Random Forest classifies slope hazard as Low, Moderate or High using inspection data from 355 highway slopes.

The supplied synopsis proposes a wider IoT and early-warning system. The interface reflects the implemented tabular classifier; it does not present sensor monitoring or event forecasting as completed features.
